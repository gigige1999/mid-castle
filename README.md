# CASTELLUM · 石墙之内

以公元 10 世纪前后的西欧为背景的 3D 城堡交互书。旧羊皮纸色、浅暖石砖、橡木、灰绿屋顶与暗红织物，模型通过 Three.js 实时渲染。

## 使用

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 生成 `dist`，可部署至任意静态网站服务；`npm run preview` 预览构建产物。

线上地址：https://gigige1999.github.io/mid-castle/

推送 `main` 后，GitHub Actions 自动构建并发布到 GitHub Pages。Pages 使用 GitHub Actions 作为来源；工作流以 `/mid-castle/` 为资源基础路径构建，平面图也会随路径调整。可在仓库 Actions 中查看发布进度，或手动运行 `Publish castle to GitHub Pages`。本地验证同样的发布版本：`npm run build -- --base=/mid-castle/`。

## 交互

- 城堡剪影加载后显示全屏城堡与开始按钮。首页城堡缓慢环绕，拖动后暂停；点击开始或城堡后选择角色：领主、守卫、司铎、厨师、管事、铁匠、缮写员、草药师、织工。角色选择窗提前展示房间分配，确认后淡出，镜头连续进入所属房间。
- 角色选择保存在当前浏览器；下次打开时预选原角色，仍由你确认。顶部可更换身份、返回「我的房间」。
- 九位角色都有独立的 3D Q 版造型：王冠与披风、头盔与盾牌、礼袍与经书、厨师帽与木勺、钥匙与账本、围裙与铁锤、羽毛笔与抄本、药草篮与陶罐、梭子与线团。选角卡片显示真实立体人物，选中后挥手欢迎。
- 确认身份后，人物出现在所属房间。点击空地，或用 WASD / 方向键行走；手机可按住方向按钮。人物有转身、步态和待机动作，行走范围避开主要家具、建筑、城墙与水面。
- 「去庭院散步」进入室外活动区域，「找到我」聚焦角色；可随时暂停漫游。点击建筑或目录进入另一房间时，人物从该空间的入口继续活动，跨空间采用位置切换。
- 每个角色拥有三件「今日小事」，共 27 项任务。先收集任务所需物品，部分任务还需要和指定居民交谈；再前往对应空间，点击底部动作按钮或按 E 完成。完成会消耗一份物品、获得一枚铜色纪念章，并展示角色动作与知识反馈。切换角色保留各角色已经完成的任务。
- 13 种独立造型的 3D 物品分布在城堡各处，包括亚麻布、蜂蜡烛、羊皮纸、铜钥匙、织花缎带、面包、苹果、锻铁料、麦穗、香草、羽毛笔、草药膏和染色线团。靠近后拾取，物品进入行囊；同一地点每 15 秒补充一份，送礼或完成任务消耗后可以再次收集。
- 庭院中有 9 位各有名字与近况的居民，可以交谈、打听物品线索，并赠送对方所需的物品。每位居民首次收到礼物会增加友谊，并赠你一枚铜色纪念章；之后仍可继续聊天。
- 点击「行囊」或按 B 查看库存、已发现物品图鉴和 7 项纪念成就。首次拾取、发现 5 种、10 种或全部 13 种物品、结识 3 位居民、帮助 3 位居民、完成 3 项任务都会解锁对应成就。物品使用后，图鉴中的发现记录继续保留。
- 库存、发现记录、居民交往、任务、成就和纪念章自动保存在当前浏览器，刷新后恢复。清理网站数据、更换浏览器或网站地址后进度不会共享；浏览器不允许存储时仍能继续游玩，但关闭页面后无法恢复这一轮进度。
- 首页、行走和房间展开共用同一个全屏画布，镜头平滑过渡。详情通过「房间介绍」展开，关闭介绍后继续留在当前房间；点击「城堡总览」返回全景。
- 13 个室内空间均可展开：卧室、大厅、礼拜堂、议事厅、储藏室、厨房、守卫居所、马厩、铁匠铺、粮仓、缮写室、草药医舍、织造坊。通过屋顶、标记或完整空间目录进入，点击「城堡总览」合拢并返回先前视角。
- 新增缮写室的抄写案与书卷架、草药医舍的休息卧榻与药架、织造坊的经纬织机与染盆。三位新角色各有三项任务，也以有名字的居民出现在庭院，支持交谈与赠礼。旧存档继续保留。
- 建筑外观补充了拱券窗、门扇铁箍、转角石、挑檐桁架、屋脊瓦、主堡扶壁与城门机构。屋顶和外墙细节随房间一起展开，不遮住室内。
- 室内具有木床、织毯、祭坛、书卷、餐具、食品罐、兵器架、鞍具、量斗与锻造器具等不同陈设。石砖凹凸、木纹和织物纹理均在本地生成，不依赖外部模型下载。
- 拖动旋转，滚轮 / 双指缩放，右侧按钮放大、缩小、重置视角、切换名称标记。
- 18 个可点击区域，提供用途、使用者与背景说明；空间地图分为 5 组，标明当前位置和分配房间。地图按需打开，选择空间后收起；手机详情从底部展开。
- 每个区域提供独立 SVG 平面示意图，带家具、北向与编号图例，可点击放大；图纸为概念陈设示意，非遗址实测图。
- 介绍中可上传区域图片，并在「空间平面」和「区域图片」之间切换。图片仅保存在当前浏览器的 IndexedDB 中，不会上传服务器，刷新后保留。更换浏览器、清理网站数据或更换网站地址后需重新上传。
- 自适应桌面和手机布局，支持减少动画系统偏好。
- 无法使用 WebGL 时保留空间目录和文字介绍。

## 内容与模型

`src/data.js` 包含区域文字；`src/roles.js` 定义角色分房；`src/residency.js` 管理角色选择；`src/room-layouts.js` 统一室内视角与屋顶归属；`src/castle.js` 创建实体模型；`src/main.js` 管理交互；`src/navigation.js` 与 `src/navigation.css` 提供完整空间目录；`src/style.css` 控制布局和风格。`public/plans/` 与 `src/floorplans.js` 保存平面图和说明，可运行 `node scripts/generate-floorplans.mjs` 重新生成。

`src/characters.js` 提供角色造型和动作；`src/role-gallery.js` 使用单个渲染器显示选角卡片；`src/walking.js` 管理角色移动与寻路；`src/quests.js` 管理角色任务；`src/life-data.js` 定义物品、居民、成就与任务需求；`src/life-state.js` 管理库存消耗、进度与本地保存；`src/life-world.js` 呈现 3D 物品和居民；`src/life-ui.js` 与 `src/life-ui.css` 提供行囊和对话；`src/adventure.css` 定义漫游控件；`src/game-shell.css` 提供全屏首页与游戏界面。

本作品是用于科普的概念复原，并非某一实际遗址。部分成熟石堡形制参考 11—13 世纪建筑。年代差异在「关于本书」和对应区域中说明。

字体使用 Google Fonts 的 Noto Serif SC 和 DM Sans，无法连接时自动使用本地宋体和系统无衬线字体。其余模型、样式和脚本均随项目本地提供。
