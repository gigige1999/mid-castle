# CASTELLUM · 石墙之内

以公元 10 世纪前后的西欧为背景的 3D 城堡交互书。暖白纸色、石灰岩建筑、灰绿屋顶与苔绿地景，模型通过 Three.js 实时渲染。

## 使用

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 生成 `dist`，可部署至任意静态网站服务；`npm run preview` 预览构建产物。

## 交互

- 城堡剪影加载动画，点击「走进城堡」或模型打开屋顶，进入俯视剖面。
- 拖动旋转，滚轮 / 双指缩放，右侧按钮放大、缩小、重置视角、切换名称标记。
- 15 个可点击区域，提供用途、使用者与背景说明；支持前后翻页和空间目录分类。
- 点击介绍中的图片位置上传图片。图片仅保存在当前浏览器的 IndexedDB 中，不会上传服务器，刷新后保留。更换浏览器、清理网站数据或更换网站地址后需重新上传。
- 自适应桌面和手机布局，支持减少动画系统偏好。
- 无法使用 WebGL 时保留空间目录和文字介绍。

## 内容与模型

`src/data.js` 包含区域文字；`src/castle.js` 创建实体模型；`src/main.js` 管理交互；`src/style.css` 控制布局和风格。

本作品是用于科普的概念复原，并非某一实际遗址。部分成熟石堡形制参考 11—13 世纪建筑。年代差异在「关于本书」和对应区域中说明。

字体使用 Google Fonts 的 Noto Serif SC 和 DM Sans，无法连接时自动使用本地宋体和系统无衬线字体。其余模型、样式和脚本均随项目本地提供。
